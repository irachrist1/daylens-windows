# V2 feature dispositions

**Status:** Accepted product decisions.

This is not the V2 plan. Sequencing, blockers, and the release gate live in [V2-PLAN.md](../V2-PLAN.md). Product behavior lives in [docs/specs](../specs/). This document records which shipped features are in Version 2 scope.

A feature listed as in-scope is live product. Implementation must keep it working and document it as current behavior, not as leftover code.

## In scope (live)

- **Focus score.** An honest deep-work percentage: time in continuous focused sessions of 25 minutes or more, divided by total active time. It returns “not enough data” instead of a fake number when there is not enough tracked time. The score feeds day summaries, AI context, remote snapshots, and related queries. See [Focus score and distraction alerts](../specs/focus-and-distraction.md).
- **Distraction alerts.** A boot-started alerter that can warn when leisure (entertainment or social) interrupts an inferred work state, or when a person leaves the planned apps of an explicit focus session. Settings owns the on/off toggle and the threshold. Distraction events are stored with the tracked activity they came from.
- **Distraction profile.** A wrap and MCP read of the day’s leisure-versus-other split and the leisure surfaces that appeared. It is a measured split, not a grade of personal worth.
- **User-initiated focus sessions.** The person can start a focus session, label it, and review it. Distraction counting during a session stays attached to that session.

## Frozen

- **Server-side web AI over plaintext Convex data** stays frozen. No new features on the current web companion and Convex sync. They continue for already-linked people until the encrypted web companion replaces them.

## Removed

- **The carryover nudge.** It is not part of Version 2 and is deleted with the brief rebuild, not migrated. See [Briefs](../specs/briefs.md).
- **The OAuth connector framework.** Dropped 2026-07-26. Calendar and git enrichment continue through local probes. See [V2-PLAN.md](../V2-PLAN.md).
- **CLI provider modes** (`claude-cli`, `chatgpt-cli`, `gemini-cli`, `codex-cli`) are not part of Version 2. They remain unmarketed development conveniences.

## Decision

On 2026-09-07 the product call on DEV-289 was to revive focus score and the distraction alerter in the spec and keep the live code. The earlier “Removed” disposition contradicted the running product.
